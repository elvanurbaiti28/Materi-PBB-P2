# Ringkasan Materi PBB-P2 (UU 1/2022 HKPD)

Situs statis berisi ringkasan PBB-P2 lengkap dengan kalkulator interaktif.

## Struktur
```
index.html            struktur dan isi halaman
assets/css/style.css  tampilan (tema terang/gelap, responsif)
assets/js/main.js     kalkulator, tab contoh, penanda menu aktif
.nojekyll             matikan Jekyll di GitHub Pages
```

## Deploy ke GitHub Pages
1. Upload semua file di atas ke repo, pertahankan struktur foldernya.
2. Settings > Pages > Deploy from a branch > `main` / `(root)`.
3. Buka `https://username.github.io/nama-repo/`.

## Catatan
Angka pada contoh hanya ilustrasi. Tarif, NJOPTKP, dan NJKP sebenarnya ditetapkan perda tiap daerah.
"# pbb-p2-uu-hkpd"
